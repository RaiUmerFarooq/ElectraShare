# Welcome to your ElectraShare

This is a ElectraShare project created on React-Native Expo 

## Get started
1. Pull/Clone the project in the folder

2. Install dependencies

   ```bash
   npm install
   ```

3. Start the app

   ```bash
    npx expo start
   ```
4. Install Expo Go in your mobile and then scane the QR code that will shown in the cmd panel (make sure that your laptop and mobile is connected to the same network)

   After scanning you will see the app running on ur Mobile
